# Stone Scout appearance variants

These three cosmetic looks are staged but not yet connected to the combat prefab or placed in the scene. Unity's command-line licensing failed, so the shader could not be validated safely. In a normally licensed Unity editor, run **Tools > Art > Set Up Stone Scout Variants**. It checks the shader first; only then does it install the materials and group the six existing Stone Scouts. Run **Tools > Art > Check Stone Scout Variants** afterwards if needed.

The placement utility is intended to group the six placed Stone Scouts in one overworld area, two of each look. The shader reads the existing six UV palette tiles and adds restrained stone weathering and rune/eye emission. Moss geometry stays the same; its colour changes, not its physical coverage.
