HeroMotionKit — 来源与许可说明

本包用于用户当前 Unity 项目的内部资产交接。交付内容为用户主角模型及其烘焙动作、接入资料；各原始素材的许可继续适用。本包整体不是 CC0，也不构成对第三方素材的新授权。未将来源库的原始角色、付费资源原始文件或整套源动画库加入本包。

1. 当前交付与来源追溯
当前导出依据 deliverables/current_motion_index.json 中的120条选择，来自 hero_natural_current.blend，包含本轮39条自然度调整。ActionSources.json 按动作ID给出当前Action、实际选中的修整前来源、首次汇总来源和已有参考记录。
注意：motion_manifest.json 包含长期制作历史，部分参考对应已经弃用的候选。ActionSources.json 明确区分当前选择与历史参考；不能把旧版本曾引用的CC0来源，直接视为当前整条动作或整包的许可。

2. 用户角色与 Tripo/Mixamo 绑定
角色来自用户提供的Tripo主角页面，使用当前65骨Mixamo式绑定：
https://studio.tripo3d.ai/zh/workspace/animate/anime-style-male-character-wearing-black-jacket-with-silver-trim-blac-249c4f59-3801-475c-b52d-36a6458b171f
角色和用户账号生成/导出的内容仍按该账号取得内容时适用的服务条款与权利处理。本地资料未附完整账号授权凭证；不把“Mixamo骨架命名”当成一份动画的来源许可。
现有候选记录将当前核心剑术描述为在实际Tripo待机/骨架上的本地编排和修整，并非声称120条全部由网站新生成。动作中的本地调整不抹除上游素材许可。

3. Quaternius 免费动作来源
现存下载包的README明确声明CC0 1.0 Universal：
Universal Animation Library Standard：https://quaternius.com/packs/universalanimationlibrary.html
Universal Animation Library 2 Standard：https://quaternius.com/packs/universalanimationlibrary2.html
已逐字复制两个下载包的原README到Licenses目录。制作记录中的例子包括 Sitting_Idle_Loop 坐姿保持、Chest_Open 开箱，以及部分剑术/手型旧参考。每个动作的具体已记录参考见ActionSources.json；当前核心编排可能已改用后续本地来源，不一概归为Quaternius直接迁移。

4. 项目已有素材
references/project_source_inventory.json记录EX01–EX10位于 Assets/Kevin Iglesias/Human Animations，含待机、走跑、起跳/下落/落地、战斗受击和死亡等来源。
EX11–EX14为项目原有的踩水、游泳、爬墙和翻顶，原路径位于 Assets/_Staging/SwimmingAnimations 和 Assets/_Staging/Climb；其中动作名包含mixamo.com。
这些记录均明确标注“既有项目资源，沿用原资源许可；不自动认定为CC0”。本次检查未在这些源目录找到可附送的单独许可正文，故不猜测具体许可版本，也不扩大公开再分发权限。原始项目路径和来源ID保留在ActionSources.json，供项目持有人与原购买/下载记录核对。
